📝 Hoe schrijf je een goede meta description? (+ 10 Nederlandse voorbeelden)

Je meta description is de eerste kans om iemand te overtuigen op jouw zoekresultaat te klikken in plaats van dat van de concurrent. Toch worden ze op de meeste Nederlandse websites automatisch gegenereerd, leeggelaten of gekopieerd zonder nadenken. In dit artikel leer je precies hoe je een meta description schrijft die kliks oplevert — inclusief tien echte Nederlandse voorbeelden van goed én slecht.

Stel je googelt op "loodgieter Den Haag spoed". Je ziet drie resultaten. Alle drie staan op de eerste pagina, allemaal even hoog gerankt. Welke klik je aan? Waarschijnlijk degene met de meest aansprekende, concrete beschrijving onder de blauwe paginatitel. Dat is de meta description aan het werk.

Een goed geschreven meta description kan de click-through rate (CTR) van een pagina met 20 tot 30% verhogen zonder dat je één positie hoger stijgt in de rankings. Voor een drukbezochte pagina betekent dat honderden extra bezoekers per maand, alleen door één regeltje tekst te verbeteren. Wat is een meta description precies?

Definitie: meta description

Een meta description is een stukje HTML-code in de <head> van een webpagina dat een korte samenvatting geeft van de inhoud van die pagina. In de zoekresultaten van Google verschijnt het als de grijze of donkere tekst onder de blauwe paginatitel. De standaard HTML-code ziet er zo uit: <meta name="description" content="Jouw beschrijving hier." />

De meta description is niet zichtbaar op de pagina zelf — alleen in de zoekresultaten en als je de broncode van een pagina bekijkt. Zoekmachines als Google lezen de meta description als onderdeel van hun indexeringsproces. Sociale netwerken zoals LinkedIn en Facebook gebruiken hem ook wanneer iemand een link deelt: als er geen aparte Open Graph-beschrijving is ingesteld, gebruiken ze de meta description als standaard preview-tekst.

De aanbevolen maximale lengte is 155–160 tekens voor desktopweergave en circa 120 tekens voor mobiele weergave. Google kapt alles daarna af met een beletselteken (...). Er is geen vaste minimumlengte, maar te korte beschrijvingen (minder dan 50 tekens) missen de kans om de bezoeker voldoende te informeren en te overtuigen. In de praktijk is 130–155 tekens de sweet spot: genoeg ruimte voor een volledig bericht, veilig onder de grens voor afkapping.

Is een meta description een directe rankingfactor?

Nee. Google heeft meerdere keren bevestigd dat de meta description geen directe invloed heeft op waar een pagina in de zoekresultaten verschijnt. Het algoritme gebruikt de meta description niet om de relevantie of kwaliteit van een pagina te bepalen. Dit betekent dat je een perfecte meta description kunt schrijven zonder dat het je ranking verbetert — en een slechte meta description je ranking er niet door daalt.

Maar: de meta description heeft een grote indirecte invloed op je SEO via de click-through rate (CTR). Een aantrekkelijke beschrijving leidt tot meer kliks. Meer kliks op jouw resultaat ten opzichte van andere resultaten op dezelfde positie zijn een positief gebruikssignaal voor Google. Over langere perioden kan een consistent hoge CTR bijdragen aan betere posities. Bovendien is een bezoeker die naar je site klikt potentieel een klant — dus zelfs als de SEO-impact indirect is, is de businesswaarde direct.

⚠️
Google herschrijft je meta description vaker dan je denkt

Onderzoek van Portent (2024) toont dat Google de meta description herschrijft bij meer dan 60% van de zoekresultaten. Als jouw meta description niet goed aansluit bij de zoekopdracht van de gebruiker, vervangt Google hem door een relevantere passage uit je paginacontent. Reden te meer om zowel een goede meta description te schrijven als de paginatekst zelf informatief en duidelijk te houden.

De 5 regels voor een goede meta description

Een goede meta description voldoet aan vijf concrete regels. Houd deze bij de hand elke keer dat je een nieuwe pagina aanmaakt of een bestaande beschrijving herziet.

Regel 1 — Houd je aan de lengte (130–155 tekens)

Tel altijd tekens, niet woorden. Een spatie telt ook als teken. Gebruik een tekenteller (bijv. lettercount.net of de teller in Yoast SEO) om te controleren of je beschrijving niet afgekapt wordt. Zorg dat de meest belangrijke informatie in de eerste 120 tekens staat, zodat ook de mobiele weergave compleet is.

Regel 2 — Verwerk het zoekwoord (of een variatie)

Wanneer een gebruiker iets googelt, markeert Google de overeenkomende woorden in de meta description vet. Dit trekt de aandacht en verhoogt de klikgeneigdheid. Verwerk het primaire zoekwoord van de pagina dus altijd in de meta description — niet als keyword-stuffing, maar organisch als onderdeel van een leesbare zin. Gebruik ook synoniemen of gerelateerde termen die mensen kunnen gebruiken.

Regel 3 — Voeg een duidelijke call-to-action toe

Vertel de lezer wat ze kunnen verwachten als ze klikken én wat ze moeten doen. Gebruik actieve werkwoorden: "Ontdek", "Leer", "Bereken", "Bestel", "Vergelijk", "Vraag een offerte aan". Een meta description zonder call-to-action mist een kans om de bezoeker te activeren. Afhankelijk van het type pagina verschilt de call-to-action: informatief ("Leer alles over..."), commercieel ("Vergelijk prijzen en bestel direct") of transactioneel ("Vraag vandaag nog een gratis offerte aan").

Regel 4 — Schrijf uniek voor elke pagina

Een meta description kopiëren van een andere pagina op dezelfde website is een veelgemaakte fout. Google ziet dit als duplicate meta-data en toont in Search Console een waarschuwing voor "dubbele meta descriptions". Schrijf voor elke pagina een unieke beschrijving die specifiek beschrijft wat er op díe pagina te vinden is. Dit geldt ook voor productpagina's in een webshop: geen generieke "Koop dit product bij ons", maar een specifieke beschrijving per product.

Regel 5 — Schrijf in actieve, menselijke taal

De meta description is een mini-advertentietekst. Schrijf niet in de derde persoon ("Op deze pagina vindt u informatie over...") maar in de tweede persoon en de actieve vorm ("Ontdek hoe je in 5 stappen..."). Schrijf zoals je tegen een klant zou praten. Vermijd jargon, afkortingen en generieke filler-zinnen die niets toevoegen ("Welkom op onze website. Wij zijn een gerenommeerd bedrijf..."). Elke teken telt — besteed ze aan concrete informatie die de lezer overtuigt.

Stappenplan: een meta description schrijven in 5 stappen

Gebruik dit stappenplan elke keer dat je een nieuwe pagina aanmaakt of een bestaande pagina optimaliseert.

1

Bepaal het primaire zoekwoord van de pagina

Elk pagina optimaliseert voor één primair zoekwoord (of een small cluster van nauw verwante zoekwoorden). Noteer dat zoekwoord en zorg dat het in de meta description voorkomt. Gebruik de exacte term zoals mensen die googlen, niet de interne bedrijfsnaam of het jargon dat jij gebruikt.

2

Identificeer het unieke voordeel van jouw pagina

Waarom moet iemand op jóuw resultaat klikken in plaats van op dat van de concurrent? Noteer één of twee concrete voordelen: snelste bezorging, laagste prijs, gratis proefperiode, 24/7 bereikbaar, 10 jaar garantie, gecertificeerd specialist. Dit voordeel vormt de kern van je meta description.

3

Schrijf een eerste versie van maximaal 160 tekens

Schrijf een eerste versie die (a) het zoekwoord bevat, (b) het voordeel noemt en (c) eindigt met een call-to-action. Schrijf in de actieve vorm, aansprekend en concreet. Tel de tekens. Herschrijf zo nodig totdat je onder de 155 tekens zit zonder concessies te doen aan de duidelijkheid.

4

Controleer op uniciteit

Zoek in je CMS of je de beschrijving niet al ergens anders hebt gebruikt. Elke pagina verdient een unieke meta description. Gebruik de Scorio-scan of Google Search Console om snel een overzicht te krijgen van alle pagina's met dubbele meta descriptions op jouw website.

5

Implementeer en meet

Voer de meta description in via je CMS (zie de volgende sectie). Wacht minimaal 4 weken en controleer vervolgens de CTR in Google Search Console. Vergelijk met de CTR van de periode daarvoor. Herhaal het proces voor de pagina's met de laagste CTR op jouw website.

Meta description instellen in je CMS

Je hoeft geen developer te zijn om een meta description in te stellen. De meeste populaire CMS-systemen maken dit eenvoudig via een SEO-plugin of ingebouwde instelling.

WordPress met Yoast SEO

Yoast SEO is de meest gebruikte SEO-plugin voor WordPress, met meer dan 10 miljoen actieve installaties. Na installatie verschijnt onderaan elke pagina en elk bericht een Yoast-metavak. Klik op het tabblad "SEO" en scroll naar het veld "Meta omschrijving". Typ je meta description in het tekstvak. Yoast toont een kleurgecodeerde indicator: groen als de lengte goed is, oranje als hij te lang of te kort is. De ingebouwde snippet-preview laat zien hoe het resultaat eruit ziet in Google. Sla de pagina op — de meta description is meteen actief.

Shopify

In Shopify navigeer je naar de betreffende pagina, het product of de collectie in het admin-dashboard. Scroll naar het onderdeel "Zoekmachineoptimalisatie (SEO)" onderaan de pagina. Klik op "Websitepreviewer bewerken" om het veld "Meta-omschrijving" zichtbaar te maken. Vul de beschrijving in. Shopify toont direct een preview van hoe het zoekresultaat eruit zal zien. Voor producten met varianten heeft elke variant standaard dezelfde meta description als het product — overweeg voor populaire varianten aparte productpagina's met eigen meta descriptions.

Wix

In Wix open je de betreffende pagina in de editor. Klik in de linker navigatiebalk op het tandwielpictogram naast de paginanaam en kies "SEO-instellingen". Vul in het veld "Meta-tag beschrijving" je meta description in. Wix toont ook hier een preview. Let op: Wix genereert standaard automatisch meta descriptions op basis van de paginacontent. Overschrijf altijd de automatisch gegenereerde beschrijving met een handmatig geschreven versie — de automatische versie is zelden optimaal.

📌
Geen SEO-plugin? Voeg het handmatig toe

Als je een custom website hebt zonder CMS-plugin, voeg de meta description direct toe aan de HTML: zet <meta name="description" content="Jouw beschrijving hier." /> in de <head> van elke pagina. Let op: de content-waarde moet uniek zijn per pagina. Gebruik geen aanhalingstekens in de beschrijving zelf, want die breken het HTML-attribuut.

Je meta description testen en optimaliseren

Het schrijven van een meta description is stap één. Stap twee is meten of hij werkt — en zo nodig verbeteren. Het belangrijkste meetinstrument is Google Search Console (search.google.com/search-console). Dit gratis hulpmiddel van Google laat je precies zien hoeveel vertoningen en kliks elke pagina krijgt in de zoekresultaten, en berekent automatisch de click-through rate (CTR).

Ga in Search Console naar "Zoekresultaten" en klik op het tabblad "Pagina's". Sorteer op CTR oplopend (laagste CTR bovenaan). Dit zijn de pagina's met het meeste verbeterpotentieel: ze worden wel vertoond in Google, maar weinig mensen klikken erop. Begin met de pagina's die het hoogste aantal vertoningen hebben én een lage CTR — dat is waar verbetering de meeste impact heeft. Een CTR lager dan 2% voor een informatiepagina of lager dan 3–4% voor een transactionele pagina is een signaal dat de meta description (en/of de paginatitel) beter kan.

Test altijd één element tegelijk. Verander eerst de meta description, laat de paginatitel zoals die is, wacht minimaal vier weken en vergelijk de CTR. Wacht je minder dan vier weken, dan zijn de fluctuaties te groot om conclusies te trekken. Houd een eenvoudig logboek bij: datum van wijziging, oude beschrijving, nieuwe beschrijving, CTR vóór en CTR na. Dit maakt duidelijk welke wijzigingen daadwerkelijk effect hebben.

In de praktijk is een lengte van 130–155 tekens ideaal: lang genoeg om een volledig bericht over te brengen, kort genoeg om niet afgekapt te worden op mobiel. Wat de meta description wél doet, is de click-through rate (CTR) beïnvloeden: hoe aantrekkelijker de beschrijving, hoe meer mensen erop klikken. Een hogere CTR ten opzichte van de concurrentie is een indirect positief signaal voor Google en kan op termijn bijdragen aan betere posities.

Dit is een reden om zowel een goede meta description te schrijven als de paginacontent zelf helder en informatief te houden — Google pikt altijd de beste samenvatting op, ook als dat niet de door jou geschreven meta description is.

Conclusie: meer kliks zonder hogere positie

Een goed geschreven meta description is de snelste manier om meer bezoekers uit je huidige zoekposities te halen — zonder te hoeven wachten op SEO-resultaten die maanden op zich laten wachten. Je werkt met wat je al hebt: bestaande rankings, bestaande pagina's. Alleen de tekst van 155 tekens die iemand ziet voordat ze besluiten te klikken, maak je beter.
